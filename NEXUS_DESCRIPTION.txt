[size=5]Ghost of Tsushima Trainer[/size]
[i]A clean, all-in-one gameplay trainer for single-player use.[/i]

[size=4]Overview[/size]
This is a native trainer (not a Cheat Engine table you need to keep open separately) that loads alongside Ghost of Tsushima and gives you an in-game overlay menu for health, combat, movement, camera and item tweaks. Built for people who want to relax through a repeat playthrough, line up photo mode shots, breeze through a specific mission for screenshots/video, or just mess around.

Everything runs locally inside your own single-player save. Nothing touches the game's files on disk, and there's no online/network component involved.

[size=4]Features[/size]
[list]
[*][b]Infinite Health[/b] and [b]Infinite Resolve[/b]
[*][b]Fill Health[/b] / [b]Fill Resolve[/b] one-click buttons
[*][b]Stealth[/b] — enemies can't detect you
[*][b]No Detection Indicator[/b]
[*][b]Force Perfect Dodge[/b], [b]Auto Block Melee[/b], [b]Always Parry on Block[/b] / [b]Perfect Parry[/b]
[*][b]Movement Speed[/b] multiplier (adjustable slider)
[*][b]Free Camera[/b] with adjustable speed, plus one-key teleport back to your character
[*][b]Save/Load position[/b] hotkeys for quick backtracking
[*][b]Add Resource[/b] — give yourself any crafting/trade resource in any amount
[*][b]Give Gear[/b] by item hash
[*]Fully [b]rebindable hotkeys[/b] — click a key in the Hotkeys tab and press whatever you want, no config file editing
[*][b]On-screen notifications[/b] confirming every toggle
[*][b]Settings are remembered[/b] between sessions automatically
[*]One-button [b]Panic switch[/b] — instantly turns everything off and restores original game memory, handy right before you tab out or start recording
[/list]

[size=4]Installation[/size]
[list=1]
[*]Download the archive.
[*]Extract [b]version.dll[/b] into your Ghost of Tsushima install folder, next to GhostOfTsushima.exe.
[*]Launch the game as normal.
[*]Once you're loaded into the game, press [b]F8[/b] to open the trainer menu (this key can be changed in-menu).
[/list]

[size=4]Default Hotkeys[/size]
[list]
[*][b]F8[/b] — Open/close the trainer menu
[*][b]F1 / F2[/b] — Save / teleport to saved position
[*][b]F3[/b] — Teleport player to free-camera position
[*][b]F5 / F6 / F7[/b] — Quick-toggle Infinite Health / Stealth / Free Camera (works even with the menu closed)
[*][b]F9[/b] — Panic switch (disable everything instantly)
[/list]
All of the above can be reassigned from the in-menu Hotkeys tab.

[size=4]Compatibility notes[/size]
[list]
[*]Tested on game version v1053.5.0625.1621. If Sucker Punch ships a patch, some features may briefly stop working until pattern signatures are refreshed — the Status tab has a Rescan button and will tell you what's currently detected.
[*]Uses a version.dll proxy. If you run another mod that also ships a version.dll, only one can be active in the folder at a time.
[*]Two features (Pickup Multiplier, Unlock Gear on Save Load) are visible in the UI but intentionally left disabled for this release — they need further work and I'd rather ship them off than half-working. They're on the list for a future update.
[/list]

[size=4]Safety / Disclaimer[/size]
This is intended for single-player, offline use only. It doesn't interact with anything network-related and doesn't modify files on disk. As with any memory trainer, turn it off (Panic hotkey) before doing runs you want kept "clean," and don't use it around online-adjacent features. Use at your own discretion.
